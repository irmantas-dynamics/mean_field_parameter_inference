# Parameter and Hidden-State Inference in Mean-Field Models

Code for reproducing the figures from the paper:

> **"Parameter and hidden-state inference in mean-field models from partial observations of finite-size neural networks"**
> [https://doi.org/.....](https://doi.org/.....)

---

## Requirements

### Python

Install the following packages (see individual source files for version-specific requirements):

| Package | Description |
|---------|-------------|
| `numpy` | Numerical computing |
| `scipy` | Scientific algorithms |
| `matplotlib` | Plotting |
| `numba` | JIT compilation for performance |
| `CyRK` | Runge-Kutta ODE integrator (Cython/Numba) |
| `joblib` | Parallel computing utilities |
| `pymoo` | Single- and multi-objective optimization |
| `ctypes` | C library interface |

### C

The C code for loss function calculation requires:

- **liblsoda** — Implements the LSODA algorithm (Petzold & Hindmarsh) for stiff/nonstiff ODE systems.
  - Source: https://github.com/sdwfrost/liblsoda
  - To compile the static library, replace the `Makefile` in `liblsoda-master/src/` with the one provided in `Supplementary_note_2/liblsoda_make/`.
- **libgomp** — OpenMP multiprocessing library.
  - Install on Debian/Ubuntu: `sudo apt install libgomp1`
- **gsl** — GNU Scientific Library.
  - Install on Debian/Ubuntu: `sudo apt install libgsl-dev`

### MATLAB

Required for all figure-generation scripts (`.m` files).
