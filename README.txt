Code for reproducing the figures from the paper titled "Parameter and hidden-state inference in mean-field models from partial observations of finite-size neural networks".
See: https://doi.org/.....

* Figs. 1 and 2 can be reproduced by script `QIF_IN/draw_Figs_1_2.m`, that uses results from folders `QIF_IN/Invasive/optimization_results` and `QIF_IN/Noninvasive/optimization_results`

* Fig. 3 is reproduced by the script `QIF_IN/Noninvasive/QIF_IN_time_series_prediction.m`

*  Figs. 4 and 5 can be reproduced by script `QIF_AD/draw_Figs_4_5.m`, that uses results from folders `QIF_AD/Invasive/optimization_results` and `QIF_AD/Noninvasive/optimization_results`

* Fig. 6 is reproduced by the script `QIF_AD/Noninvasive/QIF_AD_time_series_prediction.m`

* Fig. 7 - `QIF_IN/Fig_7/draw_FIG_7.m` that  uses  `arnold_QIF_IN.mat` and `lyap_QIF_IN.mat` files, which are generated by functions `arnold_QIF_IN.m` and `lyapunov_QIF_IN_K.m`, respectively.

* Fig. 8 - `QIF_AD/Fig_8/draw_FIG_8.m` that uses `arnold_QIF_AD.mat` and `lyap_QIF_AD.mat` files, which are generated by functions `arnold_QIF_AD.m` and `lyapunov_QIF_AD_K.m`, respectively.
